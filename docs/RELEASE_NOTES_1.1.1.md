# Shuusshy 1.1.1

_Stable · valid for two years from its release date_

## What's new

- **Settings names your key.** Settings → Application and Updates now shows which kind of key is
  active on this computer, with its number and dates.

Everything else is the same as in 1.1.0: VB-CABLE comes with the Windows installer, the user
guide is built in, and the macOS beta is attached.

## Updating

- **Installed with the installer:** Shuusshy offers the update under Settings → Application
  and Updates → Check for updates. Your settings and key are kept.
- **Portable edition:** download the new ZIP and replace `shuusshy.exe`, keeping the `data`
  folder.

Check downloads against `SHA256SUMS.txt` (Windows) and `SHA256SUMS-macOS.txt` (Mac). See the
[1.1.0 release notes](https://github.com/maccooiiiii/shuusshy/blob/main/docs/RELEASE_NOTES_1.1.0.md)
and the [known limitations](https://github.com/maccooiiiii/shuusshy/blob/main/docs/KNOWN_LIMITATIONS.md).
