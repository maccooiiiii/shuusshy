# Shuusshy 1.0.1

_Stable · valid for two years from its release date_

## What's new

- **A new app icon:** the "silent sushi", a shrimp sushi saying "shh".
  - It now appears on the program, the Start menu and desktop shortcuts, the taskbar and the
    Windows Apps list.
  - The installer and the uninstaller use it too; the uninstaller had a generic icon before.
- **Updated installer artwork** with the new icon.

Nothing else changed: audio processing, settings and features are the same as in 1.0.0.

## Updating

- **Installed with the installer:** Shuusshy offers the update under Settings → Application
  and Updates → Check for updates. Your settings and Pro key are kept.
- **Portable edition:** download the new ZIP and replace `shuusshy.exe`, keeping the `data`
  folder.

Check downloads against `SHA256SUMS.txt`. See the
[1.0.0 release notes](https://github.com/maccooiiiii/shuusshy/blob/main/docs/RELEASE_NOTES_1.0.0.md)
for the full feature list and the
[known limitations](https://github.com/maccooiiiii/shuusshy/blob/main/docs/KNOWN_LIMITATIONS.md).
