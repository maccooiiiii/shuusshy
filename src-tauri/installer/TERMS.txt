Shuusshy - before you install

Please read these points. Clicking "I Agree" means you accept them.

1. Local processing
   Shuusshy processes your microphone on this PC only. It records nothing, uploads nothing
   and needs no account. Shuusshy's own network use is limited to the optional update check,
   which downloads release information from GitHub (you can turn it off; release 1.0.0 has
   none). Windows' WebView2 component, which draws the window, may contact Microsoft services
   on its own; it receives no audio or settings from Shuusshy.

2. Two-year validity of each release
   Every official Shuusshy release is valid for two years from its release date. The dates
   are shown in Settings > Application and Updates.
   - 30 days before the end you see a reminder, and 7 days before a warning.
   - When a release expires, noise cancellation and the virtual microphone stop until you
     install a newer release. Your settings are kept and nothing is uninstalled. You can
     still export your settings and open the download page.
   Newer releases restart the two-year period. The check uses this PC's clock and works
   offline.

3. Shuusshy Pro
   RNNoise noise cancellation is free. DeepFilterNet, voice isolation and the presets built on
   them need a Shuusshy Pro license key, checked offline on this PC.

4. Virtual microphone
   Shuusshy uses VB-CABLE by VB-Audio Software, which you install separately from the
   VB-Audio website under VB-Audio's own terms. Shuusshy does not install or change drivers.
   If you choose to rename the virtual microphone "Shuusshy Microphone", Windows asks for
   permission first, and the uninstaller offers to undo it.
