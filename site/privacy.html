Privacy policy

Shuusshy processes your microphone only on your computer.

What Shuusshy does not do

  • It does not record or store your microphone audio. The live test plays audio to your headphones in real time and saves nothing.
  • It does not upload audio or send microphone content anywhere.
  • It requires no account and collects no analytics or telemetry.

Network connections

Shuusshy's own code connects to the internet for one feature only: update checks (Windows).

  • What: Shuusshy downloads the release information file (latest.json) from the official GitHub repository and, if you install an update, the signed installer.
  • When: at start-up (at most once a day) and when you click “Check for updates”. Turn it off in Settings → Application and Updates.
  • What is sent: an ordinary HTTPS request to GitHub. GitHub sees your IP address and a standard user agent, as with any download. Shuusshy sends no identifiers, settings or audio.
  • The macOS test build makes no update checks.

Opening the VB-CABLE, BlackHole or GitHub Releases pages uses your web browser, and only when you click.

Microsoft WebView2 (Windows)

  • Shuusshy's window on Windows is drawn by Microsoft Edge WebView2, a component of Windows.
  • WebView2 can contact Microsoft services on its own: on the test PC, two HTTPS connections to Microsoft servers were open after start-up.
  • Shuusshy starts WebView2 with background networking, component updates, SmartScreen, sync and pings turned off, which reduces this but does not remove it entirely.
  • These connections carry no audio and no Shuusshy settings: the audio never enters WebView2, and Shuusshy sends nothing through it.

On macOS the window is drawn by WebKit, which is built into macOS.

What is stored on your computer

  • Settings, including your Pro license key, in a local database:
    • Windows (installed): %APPDATA%\com.shuusshy.app
    • Windows (portable): the data folder beside shuusshy.exe
    • macOS: ~/Library/Application Support/com.shuusshy.app
  • The embedded browser's cache: %LOCALAPPDATA%\com.shuusshy.app on Windows (or data\webview when portable).
  • If you turn on start at sign-in: one entry in your Windows sign-in list (HKCU Run), or a LaunchAgent file in ~/Library/LaunchAgents on macOS.
  • If you rename the virtual mic (Windows): the VB-CABLE recording device's display name.

Uninstalling on Windows removes the program and the sign-in entry; it keeps your settings unless you tick “Delete the application data”. On macOS, see the manual's Uninstalling topic.
